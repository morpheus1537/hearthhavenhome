# Hearth & Haven Home — static affiliate blog

Plain HTML/CSS generated by `build.py` (Python 3, no dependencies).

## Add a new post
1. Put a hero image (your Pinterest pin, ~800px wide JPG) in `assets/`. Never use Amazon product photos.
2. In `posts.py`, add a function returning the post HTML. Use `aff('key','Product name')` for inline links and `btn('key')` for buttons — they add the `hearthhaven0b-20` tag, `rel="sponsored nofollow noopener"` and open in a new tab. New products: add the ASIN to the `P` dict in `build.py`.
3. Add an entry to the `POSTS` list (slug, title, desc, image, date, body). Don't write exact prices — say "under $30".
4. Run `SITE_URL=https://<user>.github.io/hearthhavenhome python3 build.py` (rebuilds every page, sitemap.xml and robots.txt; the disclosure is added automatically).
5. Commit and push; GitHub Pages redeploys in about a minute.
